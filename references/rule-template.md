# 个人 AI 记忆档案 · 标准 Markdown 模板

以下为标准输出模板。方括号 `[]` 为待填充内容，无对应信息的维度可整节删除或标注「未指定」。每节标题后用括号标注**内容层**（记忆 / 偏好 / 规则）。其中身份背景、兴趣与专业、工作方式与工具、边界与禁忌为**稳定项**，沟通偏好、回答规则、当前关注与目标为**易变项**——用户日后说「更新我的档案」时，优先只改易变项，稳定项除非用户明确说明否则不动。

````markdown
# 我的个人档案

> 建档时间：[YYYY-MM-DD]　更新时间：[YYYY-MM-DD]　建档模式：[快速 / 完整]

## 身份背景（记忆）

- 称呼：[希望 AI 怎么称呼你]
- 城市：[所在城市]
- 职业 / 技能：[职业与擅长技能]
- 常用设备 / 语言：[常用设备、语言、环境]

## 沟通偏好（偏好）

- [语气，如：正式书面语 / 亲和口语 / 极简直接]
- [是否接受寒暄与恭维，如：不寒暄、不恭维，直接说事]
- [语言，如：使用简体中文回复]

## 回答规则（规则：我希望 AI 这样回复）

- [格式，如：默认 Markdown，标题分层清晰]
- [结构，如：结论先行，再展开依据]
- [长度，如：默认精炼，50-70 行以内]
- [元素，如：重要结论加粗、用列表、适当用表格；不用 emoji]

## 兴趣与专业（记忆）

- [关注领域，如：历史、NBA、数码科技]
- [擅长技能，如：Python、PC 硬件、云服务]
- [长期爱好，如：本地影音、阅读]

## 工作方式与工具（记忆）

- [常用工具，如：Windows、VS Code、GitHub]
- [工作习惯，如：效率优先、少绕弯]
- [是否主动，如：能自己查证的先查证再回答]

## 边界与禁忌（规则）

- [不碰话题 / 操作，如：不提供医疗、法律等专业意见]
- [隐私要求，如：不主动记录、不外传个人信息]
- [拒绝方式，如：遇到违规请求直接说明无法协助]

## 当前关注与目标（记忆）

- [正在推进的事，如：某项工程答辩、某项评审汇报]
- [长期目标，如：……]
````

## 如何存入 AI 记忆

### 通用方式

1. 全选上方代码块内容并复制（不含外层的 ```` 标记）。
2. 打开 AI 工具（如 WorkBuddy）的个人记忆 / 偏好设置，或保存为长期记忆文件。
3. 粘贴并保存；AI 从此按这份档案认识你、回应你。

### WorkBuddy 专属落地（可选）

若你用的是 WorkBuddy，可直接把对应条目写入以下文件（均在你的工作区 `.workbuddy` 或用户目录 `~/.workbuddy` 下）：

| 档案段落 | 建议落点 | 说明 |
|---------|---------|------|
| 身份背景 / 兴趣 / 工具 / 关注 | `USER.md` | 用户长期档案，AI 每次会话会读取 |
| 沟通偏好 / 回答规则 / 边界 | `SOUL.md` 或 `MEMORY.md` | 你的"人设"与回复规则 |

> 注意：以上文件有各自的前置元信息（frontmatter，用 `---` 包裹）与固定结构，粘贴时按目标文件的既有格式合并，不要破坏原结构。若不熟悉，把通用 Markdown 版发给 AI 说"帮我把这份档案写进 USER.md / MEMORY.md"即可。

### 带 frontmatter 的完整导出（推荐给 WorkBuddy 用户）

若要直接落地到 WorkBuddy，可输出以下带 frontmatter 的版本（`---` 之间为目标文件要求的元信息字段，按实际文件要求填写）：

**USER.md（身份 / 记忆类）**

```markdown
---
Name: [称呼]
What to call them: [称呼]
City: [城市]
Profession: [职业 / 技能]
Notes: [常用设备 / 语言 / 兴趣 / 关注]
---

# 关于我

- 职业 / 技能：……
- 兴趣与专业：……
- 工作方式与工具：……
- 当前关注与目标：……
```

**MEMORY.md / SOUL.md（偏好 / 规则类）**

```markdown
---
summary: "个人偏好与回答规则"
---

# 沟通偏好

- 语气：……
- 寒暄：……

# 回答规则

- 格式：……
- 结构：……
- 长度：……

# 边界与禁忌

- 不碰：……
- 隐私：……
```

> frontmatter 字段名以目标工具的既有文件为准（不同工具字段名可能不同），上方为常见示例。

## 优化模式（场景 B：已有档案优化）

当用户粘贴已有档案 / 零散信息 / USER.md / MEMORY.md 时，输出结构同上，但额外附一份「变更清单」：

| 变更类型 | 条目 | 说明 |
|---------|------|------|
| 新增 | [维度 / 条目] | 原档案缺失，本次补齐 |
| 修改 | [维度 / 条目] | 原信息过时或冲突，本次修正 |
| 删除 | [维度 / 条目] | 冗余 / 重复 / 不合规，本次移除 |
